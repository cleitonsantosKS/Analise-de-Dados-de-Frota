# An-lise-de-Dados-de-Frota---Automa-o
Este repositório contém scripts em Python desenvolvidos para auditar e analisar os dados de telemetria e despacho (FMS) de frotas de mineração/transporte. O foco principal é a **identificação de anomalias de automação** (falsos positivos, tempos excedidos, perda de GPS) e a geração de relatórios investigativos para as equipes de Automação.
